## Four Beats

1. **Name the sheet.** Give the ProfiCAD session a short title before you place symbols.
2. **Pin the live devices.** Keep current symbols and wire nets on the ProfiCAD board and leave unused library parts aside.
3. **Check the nets.** Read the ProfiCAD summary of crossings before you change a connection.
4. **Close the loop.** Note which title block is current so the next ProfiCAD visit does not start by searching the sheet.

## First Questions

**Does ProfiCAD replace the panel layout on the shop bench?**  
No. ProfiCAD sits beside the enclosure drawing and the parts list you already use.

**Can two electricians share one computer?**  
Yes. Each person keeps a separate ProfiCAD profile.

**Will ProfiCAD stay workable on an older shop laptop?**  
Yes. ProfiCAD is meant to stay light during a normal sheet review.

**What should a new user try first?**  
One small ProfiCAD schematic sheet today, then the same wire nets again tomorrow.

## Field Note

ProfiCAD is easier to trust when the sheet stays smaller than the full panel it came from. A named session shows which schematic is active, the pins show which symbols you will touch today, and the closing note tells the next person how the wire nets cross the sheet. That record is short on purpose: not a copy of every symbol, only the path back to the drawing that is still open.

The same loop fits a student circuit, a client control panel, or a computer shared by two electricians. Open the last ProfiCAD session, finish one net, and leave the title block easier to read than you found it. The enclosure drawing stays where it is. ProfiCAD only holds the schematic sheet, the summary, and the handoff.

## One Real Pass

Pick a panel that already has a name: a lighting board, a motor starter, or a small control circuit. Open it in ProfiCAD, keep only those symbols on the board, and trace one wire net you can point to. A pass is done when that net is labeled and the extra symbols are no longer in the way. ProfiCAD does not need a full redraw of the shop before it is useful.

If the pass feels crowded, the sheet is too wide. Drop anything that belongs to a different panel and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first symbol to the title block, with the summary still matching the wire nets on the board.
